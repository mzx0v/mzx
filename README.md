# MZX Tool 🔥
![Screenshot 1](images/Screenshot%20From%202026-04-27%2023-05-32.png)
MZX is a Bash-based penetration testing and network analysis tool designed to assist in:
- Network scanning
- Information gathering
- System monitoring

---

## 🚀 Features
- Multiple Nmap scanning modes
- IP & Port validation
- Information gathering (whois, dig, nslookup)
- System information display
- Interactive CLI interface

---

## 🛠 Requirements
- nmap
- whois
- dnsutils

---

## ⚡ Usage

`bash
sudo bash mzx.sh
